# Быстрый старт для Windows

[Скачать последний выпуск для Windows](https://github.com/ilyakichigin92/MBUprime-StructLab/releases/latest) · [English](quick-start.md) · [Руководство пользователя (англ.)](user-guide.md)

## Скачать и запустить

1. В разделе **Assets** скачайте `MBUprime-StructLab-<version>-windows-x64-unsigned.zip` и файл контрольной суммы `.zip.sha256`. Вместо `<version>` будет номер выпуска на этой странице. **Source code (zip)** и **Source code (tar.gz)** — архивы исходного кода, а не готовое приложение.
2. Перед распаковкой сравните SHA-256 архива со значением в файле контрольной суммы. Команда PowerShell `Get-FileHash -Algorithm SHA256 "C:\Downloads\your-downloaded-file.zip"` выводит хеш; замените пример пути путём к скачанному ZIP. Хеш проверяет содержимое файла, но не удостоверяет издателя.
3. Распакуйте **весь ZIP** в короткий путь только с ASCII-символами, например `C:\MBUprimeStructLab`. Файл `MBUprime StructLab.exe` должен оставаться рядом с папкой `_internal`. Не запускайте программу внутри ZIP и не переносите отдельно исполняемый файл.
4. Откройте `MBUprime StructLab.exe`. Python и все четыре вычислительных движка уже включены; устанавливать Python не нужно. Публичная сборка открывается на английском. Выберите **Русский** в переключателе **Language**.

Исполняемый файл не подписан. Средства защиты Windows могут запросить подтверждение или заблокировать запуск согласно локальным правилам; скачивайте программу со страницы выпусков проекта и соблюдайте правила своей организации. Не-ASCII-символы в полном пути могут помешать загрузке Primer3. Используйте указанный выше путь, включая все родительские папки.

Есть результаты запуска на Windows 10 22H2, сборка 19045. Проверка в чистой Windows 11 ещё не выполнена; маршруты Ubuntu и macOS остаются непроверенными. См. [статус платформ (англ.)](platforms.md).

## Выполнить синтетический пример

1. Выберите **Пакетный ввод / мультиплекс** (**Bulk / multiplex**) и замените содержимое поля двумя строками из [bulk.txt](../examples/small-panel/bulk.txt):

   ```text
   F_demo GCGCAAAAGCGC
   R_demo GCGCTTTTGCGC
   ```

2. Оставьте условия реакции по умолчанию и нажмите **Анализ** (**Analyze**). Дождитесь завершения расчёта перед просмотром новых результатов.
3. Просмотрите температуры плавления (**Melting temperatures**), отмеченные структуры (**Flagged structures**), матрицу (**Matrix**) и структуры (**Structures**). Выберите структуру для просмотра подробной геометрии или диаграммы.
4. Нажмите **Экспорт…** (**Export**), выберите отчёт TSV и сохраните его в доступную для записи папку. Откройте файл в текстовом редакторе или электронной таблице. Названия полей остаются английскими при обоих языках интерфейса.

В [описании выполненного примера (англ.)](../examples/small-panel/README.md) указаны его действительные исторические версия и настройки. Это синтетическая демонстрация, а не экспериментально проверенный ПЦР-анализ. Прогнозы служат для предварительной оценки и не доказывают работоспособность анализа в лаборатории. См. [методы и ограничения (англ.)](methods.md).

На небольшом экране используйте внешние полосы прокрутки каждой из двух колонок, чтобы добраться до нижних элементов. Разделитель позволяет менять ширину колонок. При ошибке запуска выполните [самопроверку (англ.)](user-guide.md#start-the-desktop-application) и сообщите версию программы, версию Windows и диагностику без конфиденциальных данных в [Issues](https://github.com/ilyakichigin92/MBUprime-StructLab/issues).
